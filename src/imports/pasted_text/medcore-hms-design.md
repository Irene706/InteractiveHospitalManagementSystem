# MedCore Hospital Management System — Master Design Prompt

Design a **modern, premium, highly interactive Hospital Management System called “MedCore HMS.”** The interface should feel clean, trustworthy, professional, intelligent, and technologically advanced while remaining extremely easy for hospital staff to use.

## 1. Visual Identity

Use a **medical green + white** color system.

* Primary: clean medical green, approximately **#16A36A–#159A63**
* Dark green: approximately **#087A4F** for emphasis
* Light green: approximately **#EAF8F1** for backgrounds and selected states
* White: **#FFFFFF** as the dominant surface/background color
* Text: dark charcoal rather than pure black
* Secondary text: soft gray
* Borders: very subtle light gray/green
* Avoid dark navy, excessive blue, neon green, or forest-green tones.

The overall feeling should communicate:

**Cleanliness + Healthcare + Trust + Calmness + Technology.**

Green should be used strategically for buttons, icons, active navigation, charts, status indicators, and important highlights—not everywhere.

## 2. Design Style

Create a **clean modern SaaS/healthcare dashboard aesthetic**.

Use:

* Generous whitespace
* Rounded cards
* Soft shadows
* Thin subtle borders
* Medium corner radius
* Minimal visual clutter
* Elegant typography
* Consistent spacing
* Clear hierarchy
* Professional medical iconography
* Smooth micro-interactions

Avoid excessive glassmorphism. Keep the interface primarily **clean, flat, and clinical**, with very subtle depth.

## 3. Layout

Create a responsive application layout consisting of:

### Sidebar

White sidebar with:

* MedCore logo
* HMS version
* Dashboard
* Emergency
* Patients
* Doctors
* Appointments
* Medical Records
* Pharmacy
* Laboratory
* Billing
* HR & Staff
* Settings

Organize navigation into sections such as:

**CORE**
**CLINICAL**
**SERVICES**
**ADMIN**

Emergency should have a subtle red alert indicator.

Include the logged-in administrator profile at the bottom.

### Top Navigation

Include:

* Page title
* Current date
* Global search
* Notifications
* Live system status
* User profile

Keep the header minimal and spacious.

# 5. Analytics

Create beautiful interactive charts for:

### Patient Flow

Display:

* Admissions
* Discharges
* Emergency cases

Use different shades of medical green rather than unrelated colors.

### Department Distribution

Use a clean donut chart showing:

* Cardiology
* General
* Maternity
* Emergency
* Orthopedics
* Neurology

### Revenue vs Expenses

Use a clean bar chart with green as the primary revenue color and a very light green/gray for expenses.

### Bed Occupancy

Use horizontal progress bars showing occupancy for:

* General
* ICU
* Maternity
* Cardiology
* Orthopedics

Use green for healthy availability and amber/red only when capacity becomes critical.

---

# 11. Typography

Use a modern clean sans-serif font such as:

**Inter, Manrope, or Plus Jakarta Sans.**

Use strong typography hierarchy:

* Bold page titles
* Medium section headings
* Clear readable body text
* Smaller muted supporting text

Avoid decorative fonts.

---

# 12. Accessibility

Ensure:

* Strong text contrast
* Clear focus states
* Keyboard navigation
* Readable typography
* Proper button sizing
* Meaningful icons
* Color should never be the only way to communicate status

---

# 13. Overall Experience

The final interface should feel like:

**A premium healthcare SaaS platform + modern hospital command center.**

It should be:

**Clean**
**Medical**
**Professional**
**Interactive**
**Responsive**
**Trustworthy**
**Intelligent**
**Scalable**

Use **medical green and white as the defining visual identity**, with green providing energy and healthcare association while white provides cleanliness and clarity.

Do not make the interface overly green. Maintain a balanced **white-first design with strategic medical-green accents**.

The result should look polished enough to represent a real modern hospital system rather than a generic admin dashboard.
